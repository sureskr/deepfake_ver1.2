# ML engine — Windows (Azure VM) deployment

## What exists in the repo today

| Item | Location |
|------|-----------|
| **ML inference (Wav2Vec2 + linear head)** | `ml_engine/inference.py` — class `DLInferenceLarge`, method **`predict_single(audio_path)`** → sigmoid **score** (higher ≈ more fake). |
| **CLI / batch eval** | `inference.py` main, `evaluate.py`, `infer_only.py` ( **`infer_only.py` has hardcoded `C:\vdfk_engine_dev\...` paths — do not use on VM** ). |
| **Physics engine (no NN)** | `deepfake-engine/engine.py` — **`detect(path)`**; not used by this HTTP API. |
| **Stdio GPU worker** | `deepfake-engine/ml_worker.py` — different checkpoints under `vfx_repo`; **not** HTTP; **not** this task. |
| **HTTP `/predict`** | **Did not exist** before; added here as **`windows_deployment/api_server.py`**. |

## Python / dependencies

- **Python:** 3.10 or 3.11 x64 recommended (match your PyTorch wheel availability on Windows).
- **Base deps:** `ml_engine/requirements.txt` (torch, transformers, librosa, soundfile, …).
- **API deps:** `windows_deployment/requirements-server.txt` (FastAPI, Uvicorn, multipart).

## Model files to copy

1. **Checkpoint:** `ml_engine/models/finetuned/best_model.pth` (or your chosen `.pth`).  
   - If missing in repo, copy from your training machine.  
   - Override path with env **`ML_MODEL_PATH`** (absolute path on VM).

2. **Threshold (optional):** `ml_engine/models/finetuned/threshold.txt` (e.g. `0.7000`) or set **`ML_THRESHOLD`**.

3. **Hugging Face backbone:** `DLInferenceLarge` uses **`Wav2Vec2FeatureExtractor`** + **`Wav2Vec2Model`**. Without **`ML_WAV2VEC_LOCAL`**, it downloads from the **`model_name`** in the checkpoint (often `facebook/wav2vec2-large-xlsr-53`).  
   - Set **`ML_WAV2VEC_LOCAL`** to a local folder (e.g. `models\wav2vec2-large-960h`) with `config.json`, `preprocessor_config.json`, and **`pytorch_model.bin`** or **`model.safetensors`** for offline use.  
   - **`run_ml_server.ps1`** sets **`ML_WAV2VEC_LOCAL`** automatically if `models\wav2vec2-large-960h` exists.

4. **Manual sync from dev machine:** See **`windows_deployment/COPY_TO_SERVER.txt`** — copy **`windows_deployment/inference.py`** to **`C:\ml_engine\inference.py`** when you patch inference without re-zipping the whole tree.

5. **Local `models/wav2vec2-large-960h`:** in-repo may be configs only; add full weights on the VM for **`local_files_only`** load.

## `deepfake-engine` on the VM?

- **Not required** for the Wav2Vec **POST /predict** service described here.  
- Copy **`ml_engine`** only (plus model weights / HF cache as above).

## Install and run on Azure VM

```powershell
cd C:\MlEngine
.\windows_deployment\run_ml_server.ps1
```

Or manually:

```powershell
cd C:\MlEngine
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
pip install -r .\windows_deployment\requirements-server.txt
$env:PYTHONPATH = (Get-Location).Path
python -m uvicorn windows_deployment.api_server:app --host 127.0.0.1 --port 8000
```

## Packaging from laptop → VM (zip)

Zip the **`ml_engine`** directory, including:

- `inference.py`, `requirements.txt`, `windows_deployment\` (whole folder)
- **`models\finetuned\best_model.pth`** and **`threshold.txt`** (if you have them)
- Optionally **HuggingFace cache** directory (see `HF_HOME` / `%USERPROFILE%\.cache\huggingface`)

Extract on VM e.g. to **`C:\MlEngine`**, then run `run_ml_server.ps1`.

## Validate

Health:

```powershell
curl.exe http://127.0.0.1:8000/health
```

Predict (use a real chunk path from the bot):

```powershell
curl.exe -X POST http://127.0.0.1:8000/predict -F "file=@C:\TeamsCallingBot\captures\chunks\call_XXX_chunk_001.wav"
```

Expected JSON shape:

```json
{
  "label": "REAL",
  "score": 0.42,
  "confidence": 0.58,
  "model": "best_model.pth"
}
```

## TeamsCallingBot alignment

- Bot uses **multipart field name `file`** and **`POST /predict`** — matches this API.
- Bot **`ML:BaseUrl`** should be `http://127.0.0.1:8000` and **`PredictEndpoint`** `/predict` on the VM.

## Common issues

| Issue | Mitigation |
|-------|------------|
| `model not loaded` / 503 | Set **`ML_MODEL_PATH`** to the real `.pth` path; confirm file exists. |
| Slow first request / download | Pre-cache Hugging Face model or set **`HF_HOME`** from laptop. |
| torch CUDA | `inference.py` forces **CPU** in `DLInferenceLarge`; GPU not required for this path. |
| Missing `.pth` in git | Supply artifact from training; not generated by this repo. |
