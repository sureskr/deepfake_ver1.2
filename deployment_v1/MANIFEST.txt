Deployment instructions:

PRE-FLIGHT (on server):
1. Confirm GPU is available:
     py -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0))"
2. Install new dependency:
     pip install miniaudio>=1.2

DEPLOY:
3. Back up old model:
     cp models/best_model.pth models/best_model.pth.bak_v0
4. Copy new model weights:
     deployment_v1/models/best_model.pth -> server models/best_model.pth
5. Copy threshold file (NEW):
     deployment_v1/models/threshold.txt  -> server models/threshold.txt
6. Replace inference worker:
     deployment_v1/ml_worker.py -> server ml_worker.py
7. Set environment variables (or edit paths in ml_worker.py directly):
     VFX_MODEL_PATH = <server path>/models/best_model.pth
     VFX_W2V2_DIR   = <server path>/models/wav2vec2-large-960h
     VFX_THR_PATH   = <server path>/models/threshold.txt
8. Restart inference service

VERIFY:
9. Run smoke test on a known-fake file — score should be >= 0.70
   Run smoke test on a known-real file — score should be < 0.70
10. Check accuracy on held-out sample — should exceed 70% (was 66.76%)

ROLLBACK (if needed):
   cp models/best_model.pth.bak_v0 models/best_model.pth
   rm models/threshold.txt  (or set to 0.5000)
   Restore old ml_worker.py

Known limitations of V1:
- Domain shift on ASVspoof 2021 LA (TTS/vocoder attacks):
    Accuracy 58.7%, AUROC 0.653 — model was not trained on lab-style TTS
    Fix in progress: V2 adds 1,000 LA calibration samples (eval pending)
- FNR 49.78% at threshold=0.70: model misses ~50% of fakes
    This is the precision/recall tradeoff at FPR<15% operating point
    Lowering threshold to 0.55 gives FNR~20% but FPR~36%
